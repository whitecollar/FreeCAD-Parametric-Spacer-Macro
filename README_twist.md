# FreeCAD Parametric Spacer Macro

Параметрический макрос FreeCAD для построения клиновидной 3D-детали по измеренным контрольным точкам профиля.

## Возможности

- профиль по набору измеренных ширин;
- сглаживание контура через B-Spline + fairing;
- локальная коррекция ширины;
- клиновидная толщина между верхом и низом;
- симметричное распределение толщины относительно `Z = 0`;
- два сквозных отверстия по осевой линии;
- готовый `Part::Feature` для дальнейшего экспорта в STL/STEP.

## Запуск

1. Открой FreeCAD.
2. Перейди в `Macro -> Macros -> Create`.
3. Создай новый макрос.
4. Вставь код целиком.
5. Измени параметры в начале скрипта.
6. Запусти макрос.
7. Готовый объект появится в дереве проекта.

## Основные параметры

```python
height = 126.5

thickness_top = 30.0
thickness_bottom = 10.0

hole_diameter = 5.0
hole1_from_top = 20.0
hole_spacing = 80.0
```

### Толщина

`thickness_top` — полная толщина у верхнего края.

`thickness_bottom` — полная толщина у нижнего края.

Толщина распределяется относительно центральной плоскости `Z = 0`, поэтому обе поверхности получают наклон.

## Сглаживание

```python
samples_per_segment = 48
fair_passes = 8
fair_strength = 0.22
```

- `samples_per_segment` — плотность точек на исходных сегментах.
- `fair_passes` — число проходов сглаживания.
- `fair_strength` — сила одного прохода.

Практический диапазон `fair_strength`: примерно `0.15 ... 0.30`.

Если контур начинает заметно уходить от реальных размеров, уменьши `fair_strength`.

## Локальная коррекция ширины

```python
side_correction = 0.35
correction_start = 20.0
correction_end = 70.0
correction_ramp = 5.0
```

В этом примере в зоне 20–70 мм от верха снимается по `0.35 мм` с каждой стороны.

Полная ширина уменьшается на:

```text
0.35 + 0.35 = 0.70 мм
```

`correction_ramp` задаёт плавный вход и выход, чтобы не создавать новые углы.

## Контрольные точки профиля

Форма задаётся списком `measurements`:

```python
measurements = [
    (10.0, 29.0),
    (20.0, 36.0),
    (30.0, 41.0),
    (40.0, 42.5),
    (50.0, 42.5),
    (60.0, 42.0),
    (80.0, 40.0),
    (100.0, 34.0),
    (110.0, 29.0),
    (120.0, 20.0),
]
```

Формат каждой точки:

```text
(расстояние от верха, полная ширина)
```

Например:

```python
(40.0, 42.5)
```

означает, что на расстоянии 40 мм от верхней точки полная ширина профиля равна 42.5 мм.

## Добавление промежуточной точки

Если на 70 мм от верха измеренная ширина равна 41.2 мм:

```python
(60.0, 42.0),
(70.0, 41.2),
(80.0, 40.0),
```

Точки должны идти по возрастанию расстояния от верха.

На участках с сильным изменением формы полезен шаг 5 мм. На плавных участках обычно достаточно 10–20 мм.

## Другой профиль

Пример полностью нового набора размеров:

```python
height = 132.0

measurements = [
    (8.0, 24.0),
    (15.0, 32.0),
    (25.0, 38.0),
    (40.0, 44.0),
    (60.0, 45.0),
    (80.0, 43.0),
    (100.0, 36.0),
    (115.0, 25.0),
]
```

Верхнюю и нижнюю точки с нулевой шириной обычно добавлять вручную не требуется — макрос формирует окончания сам.

## Отверстия

```python
hole_diameter = 5.0
hole1_from_top = 20.0
hole_spacing = 80.0
```

Отверстия расположены по центральной оси `X = 0`.

`hole1_from_top` измеряется от верхней точки до центра первого отверстия.

`hole_spacing` — расстояние между центрами первого и второго отверстий.

## Практические рекомендации

- Не увеличивай количество точек только ради количества — новые точки лучше получать из реальных измерений.
- Если профиль слишком угловат в CAD, сначала работай с `fair_passes` и `fair_strength`.
- Если CAD выглядит гладко, а STL после печати гранёный, проверь качество mesh/STL.
- Для локальной ошибки по ширине используй `side_correction`, а не уменьшай весь профиль.
- После серьёзного изменения `measurements` полезно временно поставить `side_correction = 0.0`, проверить базовую форму и только потом вернуть локальную коррекцию.

## Экспорт

Для печати:

`File -> Export -> STL`

Для дальнейшего CAD-редактирования:

`File -> Export -> STEP`

## Twist: скручивание профиля в X–Y

Макрос может строить не только обычный Loft между параллельно ориентированными сечениями, но и плавно поворачивать профиль от передней к задней стороне.

Основные параметры:

```python
twist_angle_deg = 15.0
twist_sections = 9
```

### `twist_angle_deg`

Полный относительный угол между первым и последним сечением.

Примеры:

```python
twist_angle_deg = 0.0    # без скручивания
twist_angle_deg = 15.0   # поворот на 15°
twist_angle_deg = -15.0  # поворот в противоположную сторону
```

### `twist_sections`

Количество промежуточных поперечных сечений, через которые строится плавный Loft.

Практические значения:

| Значение | Когда использовать |
|---:|---|
| `7–9` | быстрые тесты, небольшой угол |
| `9–11` | хороший базовый вариант для 10–15° |
| `15–21` | если нужна более плавная поверхность или Loft выглядит нестабильно |

Чем больше `twist_sections`, тем плавнее геометрия, но тем больше вычислений выполняет FreeCAD.

### Как распределяется угол

Для каждого сечения используется нормализованный параметр `progress` от `0.0` до `1.0`:

```python
angle = twist_angle_deg * progress
```

Например, при полном Twist `15°` последовательность может выглядеть так:

```text
0° -> 3° -> 6° -> 9° -> 12° -> 15°
```

### Поворот точки в X–Y

```python
def rotate_xy(x, y, angle_deg):
    angle = math.radians(angle_deg)

    ca = math.cos(angle)
    sa = math.sin(angle)

    return (
        x * ca - y * sa,
        x * sa + y * ca
    )
```

Поворот выполняется вокруг начала координат `(0, 0)`.

### Порядок построения

Логика модели:

```text
measurements
    ↓
базовый 2D-профиль
    ↓
fairing / сглаживание
    ↓
локальная коррекция ширины
    ↓
создание N промежуточных сечений
    ↓
постепенный rotate_xy()
    ↓
Part.makeLoft(...)
    ↓
готовый Twisted Solid
```

Twist не заменяет остальные параметры:

- `measurements` задаёт форму 2D-контура;
- `fair_passes` и `fair_strength` сглаживают контур;
- `side_correction` локально корректирует ширину;
- `thickness_top` и `thickness_bottom` задают изменение толщины;
- `twist_angle_deg` задаёт пространственный поворот;
- `twist_sections` задаёт плавность этого поворота.

### Рекомендованный первый тест

```python
twist_angle_deg = 10.0
twist_sections = 9
```

После проверки можно увеличить угол:

```python
twist_angle_deg = 15.0
```

Если поверхность начинает выглядеть ступенчатой:

```python
twist_sections = 15
```

### Диагностика

- Если направление Twist неправильное — поменяй знак `twist_angle_deg`.
- Если видны продольные переломы — увеличь `twist_sections`.
- Если кромка угловатая даже при `twist_angle_deg = 0`, настраивай исходный профиль и fairing.
- Если FreeCAD показывает гладкую модель, а STL выглядит гранёным, увеличь качество mesh/тесселяции при экспорте.
